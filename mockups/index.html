デザイン案

同じ画面（スコアボード＋入力シート）を3つの方向性で作ったモックです。実機で触って選んでください。3案は設定で切り替えられるようにする方針です。

3案を切り替えられる版

HTMLは1種類のまま、CSSトークンだけでデザインを切り替える実装。上部のバーで切り替え。直接指定 → themed.html#retro / #swiss / #retro,sheet

案A 紙のスコアシート

生成りの紙地・細い罫線・等幅数字。影を使わず線と余白で構造を作る。入力シートを開いた状態 → a-paper.html#sheet

案B レトロなゲーム箱

太い罫・角ゼロ・朱／紺／黄。硬いオフセット影で押せる物体の感じを出す。入力シートを開いた状態 → b-retro.html#sheet

案C 硬派ミニマル

白黒＋朱の1色。グリッドと余白だけで階層を作り、数字を主役にする。入力シートを開いた状態 → c-swiss.html#sheet
